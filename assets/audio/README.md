# Audio assets

`scan_loop.wav` is an original sound synthesized for ALMUS AI (a gently
pulsing 700 Hz +/- 200 Hz sweep, 2 seconds, mono 16-bit 22.05 kHz, loops
without a click). It was generated by a script from plain sine waves; no
third-party sample, library or recording is used, so there is no third-party
licence to honour. It is played only while a face scan runs, only if the user
turned the scanning sound on, and never for more than 15 seconds.
