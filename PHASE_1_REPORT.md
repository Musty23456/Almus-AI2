## 3. Verified problems fixed

1. **Chat stuck on THINKING after a non-`Exception` failure.** `send()` caught only `ChatServiceException` and `Exception`. A Dart `Error` thrown by an engine (StateError, TypeError…) would escape, leaving `_busy = true` permanently and blocking all later sends. Now any failure shows a generic error bubble and clears busy. The raw error text is never displayed. Regression test added (`test/chat_robustness_test.dart`) — **not run**.
2. **Face photos left in cache.** `image_picker` writes the capture to the app cache; the code copied it on success but never deleted the original, and never on failure/no-face/multi-face paths. Now deleted in `finally`. Not covered by an automated test (needs camera plugin mocks); manual check in `docs/BUILD_AND_TEST.md`.
3. **Missing `.gitignore`** (risk of committing `.env`, keystores, build output). Added.
4. **Build reproducibility:** CI-only inline script moved to `tool/bootstrap_android.sh` so local and CI builds are identical; project files are restored after `flutter create`.
